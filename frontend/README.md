# ursGAL — frontend

React 19 + Vite + Tailwind v4. Backend-ийн `dist`-ээс үйлчилдэг тул
дангаараа ажиллуулах шаардлагагүй; хөгжүүлэлтэд `npm run dev` (5173)
нь `/api`-г 3000 руу проксилдог.

Системийн ерөнхий тайлбар: [`../README.md`](../README.md)
Гар шалгалт, тест: [`../TESTING.md`](../TESTING.md)

```bash
npm run dev     # хөгжүүлэлт (Vite, 5173)
npm run build   # dist/ — backend үүнийг статикаар өгнө
```
